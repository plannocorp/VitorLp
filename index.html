    Sobre mim

    Sou um desenvolvedor Full-Stack apaixonado por tecnologia que iniciou sua jornada na programação aos 15 anos, em 2020. Atualmente, possuo 7 meses de experiência profissional como desenvolvedor na IPASGO, onde apliquei meus conhecimentos especialmente em C# com .NET para desenvolvimento de APIs RESTful e sistemas institucionais. Tenho experiência em resolução de problemas complexos envolvendo integração com APIs de terceiros e criação de soluções de alta performance. No front-end, domino HTML5, CSS3, JavaScript (ES6+) e TypeScript, além de frameworks/bibliotecas como Angular e React. No back-end, trabalho com Java/Spring Boot, C#/.NET, Node.js e arquiteturas REST, tanto monolíticas quanto microsserviços. Estou em formação em Análise e Desenvolvimento de Sistemas pela PUC-GO (3º período), buscando constantemente aprimorar minhas habilidades e conhecimentos através de cursos complementares. Minha paixão pela programação me motiva a enfrentar novos desafios e a evoluir continuamente como profissional, contribuindo para projetos desafiadores e inovadores. Sou o segundo membro de uma equipe de desenvolvimento Full-Stack freelancer independente, a Planno.

    HTML5

    Linguagem de marcação fundamental para estruturação de conteúdo web, permitindo a criação de documentos semânticos com elementos para texto, imagens, vídeos, formulários e outros componentes interativos que formam a base de qualquer aplicação web moderna.

    CSS3

    Linguagem de estilização que transforma interfaces web com controle preciso sobre layouts, animações, responsividade e aparência visual, possibilitando a criação de experiências de usuário atraentes e consistentes em diferentes dispositivos e navegadores.

    TS

    TypeScript

    Superset do JavaScript que adiciona tipagem estática, interfaces, classes e outros recursos avançados para desenvolvimento escalável e seguro, permitindo detecção de erros em tempo de compilação e melhor documentação de código.

    Angular

    Framework front-end para construção de aplicações web robustas e escaláveis, com arquitetura baseada em componentes, sistema de detecção de mudanças eficiente e ferramentas integradas para desenvolvimento completo.

    Python

    Linguagem de programação moderna, interpretada e dinamicamente tipada para automações rápidas, projetos de IA e APIs RESTful com Flask. Ideal para scripts de automação, machine learning com bibliotecas como TensorFlow e PyTorch, desenvolvimento de APIs leves e escaláveis, data science com Pandas/NumPy, e prototipagem ágil.

    Java

    Desenvolvimento robusto e escalável para aplicações corporativas, sistemas distribuídos, aplicativos móveis Android e soluções enterprise com tipagem forte, segurança avançada e vasto ecossistema de frameworks.

    Spring Boot

    Framework Java para desenvolvimento rápido de aplicações corporativas, monolitos, microserviços e APIs RESTful com configuração simplificada, servidor embutido e recursos prontos para produção.

    Node

    Ambiente de execução JavaScript server-side que permite construir aplicações back-end escaláveis e de alta performance com I/O não bloqueante, ideal para APIs RESTful, microsserviços e aplicações em tempo real com processamento assíncrono e vasto ecossistema de pacotes NPM.

    React

    Biblioteca JavaScript para construção de interfaces de usuário interativas e reativas, com arquitetura baseada em componentes reutilizáveis, renderização eficiente através do Virtual DOM e amplo ecossistema de ferramentas e extensões.
